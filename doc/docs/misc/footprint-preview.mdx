## Footprint Management

All footprints in this project are downloaded using [easyeda2kicad.py](https://github.com/uPesy/easyeda2kicad.py) from the LCSC/EasyEDA database.

### Adding New Footprints

```bash
# Download footprint by LCSC ID
easyeda2kicad --lcsc_id <LCSC_ID> --footprint --symbol

# Copy to project
cp ~/Documents/Kicad/easyeda2kicad/easyeda2kicad.pretty/*.kicad_mod ./footprints/kicad/
```

### Generating Preview Images

```bash
# 1. Create .pretty directory
mkdir -p footprints/kicad/zudo-bus.pretty
cp footprints/kicad/*.kicad_mod footprints/kicad/zudo-bus.pretty/

# 2. Export to SVG using KiCad CLI
kicad-cli fp export svg footprints/kicad/zudo-bus.pretty -o footprints/images --black-and-white

# 3. Remove REF** placeholder text
python3 footprints/scripts/clean-svg-refs.py footprints/images/

# 4. Copy to documentation static folder
cp footprints/images/*.svg doc/static/footprints-svg/
```
