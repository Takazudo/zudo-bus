## Reverse Polarity Protection

```
+12V Rail                              -12V Rail
    │                                      │
    │                                      │
    ├──────────────┐          ┌────────────┤
    │              │          │            │
    │          Cathode    Anode            │
    │            ┌─┴─┐    ┌─┴─┐            │
    │            │ D1│    │ D2│            │
    │            │   │    │   │            │
    │            └─┬─┘    └─┬─┘            │
    │          Anode    Cathode            │
    │              │          │            │
    │              └────┬─────┘            │
    │                   │                  │
    │                  GND                 │
    │                                      │
    ▼                                      ▼
To IDC Headers                      To IDC Headers

D1, D2: 1N4007 (1A, 1000V)
- Clamps reverse voltage to ~0.7V
- Protects modules from reversed power cable
```

## 16-Pin IDC Pinout (Eurorack Standard)

```
┌─────────────────────────────────┐
│    Eurorack 16-Pin Header       │
│         (Top View)              │
│                                 │
│   Pin 1  ●───────● Pin 2        │
│   -12V         -12V             │
│                                 │
│   Pin 3  ●───────● Pin 4        │
│   GND           GND             │
│                                 │
│   Pin 5  ●───────● Pin 6        │
│   GND           GND             │
│                                 │
│   Pin 7  ●───────● Pin 8        │
│   GND           GND             │
│                                 │
│   Pin 9  ●───────● Pin 10       │
│   +12V         +12V             │
│                                 │
│   Pin 11 ●───────● Pin 12       │
│   +12V         +12V             │
│                                 │
│   Pin 13 ●───────● Pin 14       │
│   +5V          +5V              │
│                                 │
│   Pin 15 ●───────● Pin 16       │
│   CV           GATE             │
│   (NC)         (NC)             │
│                                 │
│         ▲ Keying notch          │
└─────────────────────────────────┘

Pin Functions:
- Pins 1-2:    -12V power
- Pins 3-8:    Ground (x6)
- Pins 9-12:   +12V power (x4)
- Pins 13-14:  +5V power (x2)
- Pins 15-16:  CV/Gate (typically NC on bus boards)
```
