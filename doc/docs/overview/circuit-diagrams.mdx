## LED Indicator Circuit

```
+12V Rail                                                +5V Rail
    │                                                        │
    │                                                        │
    ▼                                                        ▼
   R2                                                       R3
  1kΩ                                                      1kΩ
    │                                                        │
    ▼                                                        ▼
 ┌─────┐                                                 ┌─────┐
 │LED2 │                                                 │LED3 │
 │Green│                                                 │Blue │
 │A → K│                                                 │A → K│
 └──┬──┘                                                 └──┬──┘
    │                                                        │
    ▼                                                        ▼
   GND                                                      GND


LED1 (-12V Indicator) - Different topology:

   GND (0V)
    │
    ▼
 ┌─────┐
 │LED1 │  Current flows from GND (higher potential)
 │ Red │  to -12V (lower potential)
 │A → K│
 └──┬──┘
    │
    ▼
   R1
  1kΩ
    │
    ▼
 -12V Rail
```

**LED Current (all 1kΩ resistors, same as zudo-power-usb-pd):**

- LED1 (Red, -12V): I = (0V - (-12V) - 2V) / 1kΩ ≈ 10mA
- LED2 (Green, +12V): I = (12V - 2V) / 1kΩ ≈ 10mA
- LED3 (Blue, +5V): I = (5V - 3V) / 1kΩ ≈ 2mA

**Note:** For LED1 (-12V indicator), the LED anode connects to GND (0V) and current flows toward the -12V rail. This is the reverse of the +12V and +5V LEDs where current flows from the positive rail to GND.

## Reverse Polarity Protection

```
+12V Rail                              -12V Rail
    │                                      │
    │                                      │
    ├──────────────┐          ┌────────────┤
    │              │          │            │
    │          Cathode    Anode            │
    │            ┌─┴─┐    ┌─┴─┐            │
    │            │ D1│    │ D2│            │
    │            │   │    │   │            │
    │            └─┬─┘    └─┬─┘            │
    │          Anode    Cathode            │
    │              │          │            │
    │              └────┬─────┘            │
    │                   │                  │
    │                  GND                 │
    │                                      │
    ▼                                      ▼
To IDC Headers                      To IDC Headers

D1, D2, D3, D4: SM4007PL (1N4007 equivalent, SOD-123FL)
- Clamps reverse voltage to ~0.7V
- Protects modules from reversed power cable
- D3: PSU +5V input path protection
- D4: LDO +5V output path protection
```

## Protection Circuit Order

```
Input → PTC Fuse → TVS Diode → Reverse Diode → Bulk Caps → Distribution

+12V Rail Example:
                                                              To IDC
Input ──► F1 (2A PTC) ──► TVS1 (15V) ──► D1 (reverse) ──► C5 (22µF) ──► Headers
          overcurrent     transient      polarity         bulk
          protection      clamp          protection       filtering
```

## TVS Transient Protection

```
+12V Rail              -12V Rail              +5V Rail
    │                      │                      │
    │                      │                      │
   TVS1                   TVS2                   TVS3
  SMF15CA               SMF15CA                SMF5.0CA
  (15V bi)              (15V bi)              (5V bi)
    │                      │                      │
   GND                    GND                    GND

Specifications:
- SMF15CA: 15V standoff, clamps to 24.4V max
- SMF5.0CA: 5V standoff, clamps to 9.2V max
- Bidirectional - protects against positive and negative spikes
```

## PTC Overcurrent Protection

```
+12V Input ──► F1 ──► +12V Rail
              BSMD1812-200 (2A hold, 4A trip)

-12V Input ──► F2 ──► -12V Rail
              BSMD1812-200 (2A hold, 4A trip)

JP1 Pin 2 ──► F3 ──► +5V Distribution ──► To IDC Headers
(after jumper) BSMD1812-150 (1.5A hold, 3A trip)

Notes:
- Self-resetting: auto-recovers after fault clears
- Protects against short circuits and overcurrent
- F3 is placed AFTER JP1 Pin 2, protecting +5V distribution
  regardless of source selection (LDO or PSU direct)
```

## Per-Header Decoupling

Each IDC header has dedicated decoupling capacitors for +12V and -12V rails.

```
+12V Rail Decoupling (per header):

+12V Rail ──┬────────┬────────┬─── ... ───┬─── To IDC Headers
            │        │        │           │
           C7       C8       C9         C14
         0.1µF    0.1µF    0.1µF      0.1µF
        ceramic  ceramic  ceramic    ceramic
            │        │        │           │
           GND      GND      GND         GND
          (J1)     (J2)     (J3)       (J8)

-12V Rail Decoupling (per header):

-12V Rail ──┬────────┬────────┬─── ... ───┬─── To IDC Headers
            │        │        │           │
          C15      C16      C17         C22
         0.1µF    0.1µF    0.1µF      0.1µF
        ceramic  ceramic  ceramic    ceramic
            │        │        │           │
           GND      GND      GND         GND
          (J1)     (J2)     (J3)       (J8)
```

**Capacitor Assignment:**

| Header | +12V Cap | -12V Cap |
| ------ | -------- | -------- |
| J1     | C7       | C15      |
| J2     | C8       | C16      |
| J3     | C9       | C17      |
| J4     | C10      | C18      |
| J5     | C11      | C19      |
| J6     | C12      | C20      |
| J7     | C13      | C21      |
| J8     | C14      | C22      |

**Purpose:**

- High-frequency noise filtering at each output
- Prevents noise coupling between modules
- Local energy storage for transient loads
- Place capacitors as close to IDC header pins as possible

## Test Points

```
┌────────────────────────────────────────────────────────────────┐
│                       Test Point Locations                      │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│  TP1 (+12V) ────── After PTC F1, main +12V rail               │
│  TP2 (-12V) ────── After PTC F2, main -12V rail               │
│  TP3 (+5V)  ────── After jumper JP1, +5V to modules           │
│  TP4 (GND)  ────── Ground reference for measurements          │
│  TP5 (LDO in) ─── +12V input to LDO U1                        │
│  TP6 (LDO out) ── +5V output from LDO U1 (before JP1)         │
│                                                                │
└────────────────────────────────────────────────────────────────┘

Usage:
- Use TP4 (GND) as reference for all voltage measurements
- TP5/TP6 useful for diagnosing LDO issues
- TP1-TP3 verify protection circuits are passing power correctly
```
